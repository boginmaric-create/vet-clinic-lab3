# Лабораторная работа №3 — сайт ветклиники «Лапка»

Одностраничный сайт ветеринарной клиники с формой записи питомца к врачу.

Поля формы: имя питомца, возраст питомца, имя владельца, тип питомца, описание болезни, номер телефона.
Все поля проверяются на JavaScript (`script.js`).

## Запуск
Откройте `index.html` в браузере.
